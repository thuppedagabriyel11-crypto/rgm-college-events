# Implemented Feature Inventory

## Portals
- Separate Admin Portal
- User Portal with Student and Organizer roles
- Role-based backend authorization

## Admin
- Dashboard statistics
- User management and enable/disable
- Add event and assign organizer
- View/update/cancel/delete events
- Approve/reject pending events
- Event-wise participant lists
- Individual participant detail/history
- Attendance oversight
- Announcement management
- Certificate generation
- Reports

## Organizer
- Dashboard
- Create event
- Update own event
- Cancel own event
- View event participants
- Mark attendance
- Publish event announcements
- Generate eligible certificates

## Student
- Registration/login
- Profile
- Browse approved events
- Event details
- Register/cancel registration
- My registrations
- Attendance history
- Announcements
- Certificates

## Certificates
- Uses supplied certificate template image as base
- Dynamic student name
- Dynamic event name
- Event date
- Issue date
- Unique certificate ID
- QR verification URL
- PDF output
- Student certificate view/download

## UI
- RGM logo
- Orange/red college-inspired theme
- Glassmorphism
- Bento-style cards
- Soft shadows and ambient glow
- Subtle 3D tilt on pointer devices
- Responsive mobile/tablet/laptop/desktop layouts
- Mobile navigation drawer
- Reduced-motion support
- Toast feedback
- Responsive tables and forms
